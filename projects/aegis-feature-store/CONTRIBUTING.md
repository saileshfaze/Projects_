# Contributing

This is Sailesh's personal portfolio reference project. Small, focused changes are welcome.

1. Create a branch and explain the engineering motivation.
2. Add a regression test for behavioral changes, especially temporal semantics.
3. Run `pytest` and `ruff check src tests scripts examples`.
4. Do not add secrets, proprietary datasets, or real customer identifiers.
5. Preserve existing event-time and availability-time constraints.
6. Describe performance implications and migration impact in pull requests.

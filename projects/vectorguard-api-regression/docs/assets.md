# Asset provenance and reproduction

All example JSON/CSV datasets are synthetic. `assets/architecture.svg` is a hand-authored SVG and can be regenerated by running `python scripts/generate_assets.py`.

Binary PDF artifacts are deliberately **not committed** through the GitHub text-file connector. To generate one locally:

```bash
pip install reportlab
python -m app.cli data/baseline_orders.json data/candidate_orders.json --output reports/evaluation.json
python scripts/generate_report.py reports/evaluation.json reports/evaluation.pdf
```

The CLI is expected to exit with status 1 for the deliberately broken candidate; continue to the PDF command regardless. No proprietary images, customer records, downloaded model weights or externally licensed assets are included.

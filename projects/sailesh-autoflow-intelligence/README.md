# AutoFlow Intelligence

AutoFlow Intelligence is a professional full-stack portfolio project for automotive sales, inventory operations, and AI-assisted customer follow-up. It is designed as a realistic organization-grade internal platform for a modern vehicle dealership or mobility company.

The project matches Sailesh Pabbisetti's resume strengths: PHP, MySQL, HTML, CSS, JavaScript, REST APIs, responsive design, data analysis, automation, and AI-ready workflows.

## What This Project Shows

- Full-stack application architecture with a PHP REST API and a modern responsive frontend
- Automotive inventory management with searchable catalog data
- Lead tracking, conversion analytics, and revenue forecasting
- AI-style assistant panel that generates sales recommendations from live data
- Dashboard charts, KPI cards, animated interactions, and polished UI/UX
- MySQL database schema for production-style persistence
- Clean repository structure, documentation, and resume-ready project wording

## Tech Stack

- Frontend: HTML5, CSS3, JavaScript
- Backend: PHP 8 REST-style endpoints
- Data: JSON seed data for local demo, MySQL schema included
- Concepts: REST APIs, data analysis, responsive UI, dashboard design, automation, AI-assisted workflows

## Run Locally

From this folder:

```bash
php -S localhost:8080
```

Then open:

```text
http://localhost:8080
```

## Main Features

- Executive dashboard with revenue, conversion, inventory, and lead metrics
- Interactive vehicle inventory with filters for category, fuel type, and search
- Sales pipeline table with lead temperature, next action, source, and status
- Analytics section with dynamic charts rendered in JavaScript
- AI sales assistant that produces prioritized recommendations using project data
- Responsive layout for desktop and mobile portfolio demos
- Professional documentation suitable for GitHub and resume presentation

# Scope, safety and ethics

This repository is a portfolio exercise using synthetic station data. STA/LTA picks can be false positives. A constant-speed 2-D approximation ignores depth, heterogeneous earth structure, travel-time uncertainty, and sensor timing errors. Synthetic accuracy cannot establish field accuracy. Do not use outputs for emergency response, civil protection, alerts, or scientific conclusions. The optional API has no authentication and must not be exposed to untrusted networks. CI is a template until copied into the repository root.

# ADR-0001 — Mixed-integer dispatch instead of greedy battery rules

Status: Accepted for reference implementation.

A greedy schedule cannot guarantee cost-minimal choices when demand charges, solar export credits, efficiency losses and end-of-horizon reserves interact. A time-indexed MILP captures these constraints and prevents simultaneous battery charge and discharge with binary mode variables. SciPy HiGHS was chosen for reproducibility and an open-source solver dependency without a commercial license. Trade-offs: mixed-integer optimization can be slow in worst cases, the model is deterministic, and input uncertainty is not explicitly optimized. Scenario analysis is preferred over pretending forecasts are perfect.
